# 叶擎慧航 Android APK 交付说明

## 交付组成

本项目的 Android 客户端使用 `烟草/1/app-release` 进行 HBuilderX 云打包。APK 内置 Vue 生产构建资源，模型推理和业务数据由公网 Django 服务提供。

- 应用名称：叶擎慧航
- Android 包名：`io.yqhh.app`
- 当前版本：1.0.7（版本号 107）
- 最低系统：Android 8.0
- API 地址：`https://8.152.4.105/api`
- 演示账号：`admin` / `123456`
- 可直接下载的调试包：`https://8.152.4.105/yeqinghuihang-debug-1.0.7.apk`

注册时用户名须为 3 至 16 位中文、字母、数字或下划线，手机号须为有效的 11 位号码；密码须为 10 至 128 位，同时包含字母和数字，不能包含用户名或手机号。服务端校验并哈希存储密码。注册按来源 IP 限制为每小时 5 次，登录为每分钟 10 次，Nginx 另有限流；频繁测试可能短时收到 HTTP 429。演示账号是已有账号，不受新密码规则影响。

1.0.7 新增服务端图形验证码（5 分钟有效、成功后一次性失效），并加入失败次数冻结。账号角色包括种植、植保、采收、烘烤、收购/质检和管理员；管理员在管理页分配角色，一个账号可以拥有多个角色。采收、烘烤、质检工作台支持批次创建、列表查询和状态记录，演示数据不会伪造真实等级、价格或检测结论。

## 打包步骤

1. 使用 HBuilderX 打开 `烟草/1/app-release`。
2. 确认 `dist/index.html`、`dist/assets` 和 `manifest.json` 均存在。
3. 右键项目，选择“发行” -> “原生 App 云打包”。
4. 选择 Android，使用测试证书或比赛要求的正式证书。
5. 下载生成的 APK，并在 Android 8.0 及以上设备安装验证。

前端源码位于 `烟草/1/app/true/tobacco`。修改源码后，在该目录运行 `npm run build`，再将 `dist` 内容同步到 `烟草/1/app-release/dist` 后重新打包。生产 API 地址由 `.env.production` 的 `VITE_API_HOST` 控制。

## 后端前置条件

打包前必须确认 `https://8.152.4.105` 可访问，并能返回登录接口响应。APK 不会在手机本地运行 Django 或 YOLO；如果该地址不可用，APK 只能打开界面，登录和识别功能会失败。

公网 IP 使用 Let's Encrypt 的 6 天短期证书。服务器 `tobacco-cert-renew.timer` 每 8 小时检查续期，续期后重载 Nginx；部署时必须保留 TCP 80 供 IP 证书续期验证，并放行 TCP 443。旧的 8081 HTTP 入口重定向到 HTTPS。Android 包装工程已禁用明文流量；HBuilderX 云打包仍需在目标手机验收。

后端以 `烟草/前后端/drf_test002` 为准，需要部署：

- SQLite 数据库及迁移结果；首次部署运行 `python manage.py migrate` 和 `python manage.py generate_sample_data`
- 本次新增的 `0016_nutrientdeficiency_verification` 迁移，更新前端后必须先更新并迁移后端
- 统一 YOLO 权重 `yolo_unified_6class_best.pt`
- 已验证可登录的演示账号和地块数据；现有数据库可能已有不同的 admin 密码，不能只凭文档假定为 `123456`

若服务器仍运行 `烟草/1/app/true/drf_test002` 旧后端，必须先升级到上述主后端再打包验收。花叶病和野火病的自动农药记录仅标记“待农技人员确认”，不提供未经核定的药剂剂量。

## 功能验收顺序

登录后依次验证地块列表、首页上传识别、病害农药记录、施肥/农药页面、数据分析、设备、策略路径和 AI 咨询。识别测试图片使用当前 `public/demo-images` 中的四种烟草病虫害样例。健康、缺钾、缺氮和缺磷没有可靠的烟草演示图，不伪造图片或标签。

图片提示“疑似缺钾”时不会自动建立缺素或追肥记录。在识别页“缺素复核记录”中，选择 N/P/K、检测报告或专家复核，并填入可核查的报告编号或复核人及日期，才会保存缺素记录。录入后检查分析页中的 N/P/K 统计；施肥用量需另依据实际检测数值和农艺方案确定。评委没有真实检测依据时，应仅测试图片识别流程，不能填写虚构的确认记录。

统一 YOLO 测试集实测（753 张、3000 个框，imgsz=640）总体 mAP50 为 0.964；烟青虫 AP50 为 0.896，低于白星病 0.964、花叶病 0.973 和野火病 0.959。该数据集没有缺氮、缺磷类别，不能从这次结果推导 N/P 准确率。完整数字见 `docs/training_results/unified_test_metrics_20260928.json`。本地 ResNet 烟草缺素实验在 31 张公开来源图片上的跨机构验证为 22/31（71.0%），缺磷 2/7；这些结果仅用于研究，不是田间准确率。2026-09-28 已部署 HTTPS 网页和新版调试 APK：`https://8.152.4.105/yeqinghuihang-debug.apk`。正式签名包及真机验收仍待完成。
