问题诊断
═══════════════════════════════════════════════════════════════

【初始问题】
✗ torch.cuda.is_available() 返回 False
✗ RuntimeError: No CUDA GPUs are available

【诊断过程】

1️⃣ 驱动检查
   ✓ NVIDIA-SMI 正常工作
   ✓ RTX 2050 被系统识别
   ✓ CUDA UMD Version: 13.3

2️⃣ CUDA Toolkit 版本
   ✓ 已安装 CUDA 11.8 (V11.8.89)
   ✓ 环境变量正确: C:\Program Files\NVIDIA GPU Computing Toolkit\CUDA\v11.8

3️⃣ PyTorch 版本冲突 [问题1]
   ✗ 原版本: PyTorch 2.5.1+cu121 (为 CUDA 12.1 编译)
   ✗ 系统版本: CUDA 11.8
   → 版本不匹配导致无法加载 CUDA 库

4️⃣ 环境变量配置错误 [问题2]
   ✗ CUDA_VISIBLE_DEVICES=1
   ✗ 系统只有 GPU 0，设置为 1 导致找不到设备

═══════════════════════════════════════════════════════════════
修复方案
═══════════════════════════════════════════════════════════════

【修复步骤1】卸载不匹配的 PyTorch
命令: pip uninstall -y torch torchvision torchaudio
结果: ✓ 成功卸载 PyTorch 2.5.1+cu121

【修复步骤2】安装匹配的 PyTorch 版本
命令: pip install torch==2.3.1+cu118 torchvision==0.18.1+cu118 torchaudio==2.3.1+cu118 --index-url https://download.pytorch.org/whl/cu118
结果: ✓ 成功安装 PyTorch 2.3.1+cu118

【修复步骤3】修正环境变量
命令: [System.Environment]::SetEnvironmentVariable('CUDA_VISIBLE_DEVICES', '0', 'User')
结果: ✓ 永久设置 CUDA_VISIBLE_DEVICES=0

使用建议
═══════════════════════════════════════════════════════════════

1. 重启终端
   新的环境变量需要重启 PowerShell 才能生效。
   如果重启后仍有问题，请重启电脑。

2. YOLOv8 训练优化
   - RTX 2050 只有 4GB 显存，建议:
   - batch_size=8-16 (不要超过16)
   - imgsz=640 (不要用更高分辨率)
   - workers=4 (减少数据加载器线程)
   - 监控显存: nvidia-smi -l 1

3. 避免显存溢出
   在训练脚本中添加:
   ```python
   import torch
   torch.cuda.empty_cache()  # 清理缓存
   ```

4. 混合精度训练
   YOLOv8 自动支持，可节省约 40% 显存:
   ```python
   model.train(
       data='unified_tobacco_dataset/data.yaml',
       epochs=100,
       batch=16,
       amp=True  # 自动混合精度
   )
   ```

故障排查
═══════════════════════════════════════════════════════════════

如果重启后 CUDA 仍不可用:

1. 检查环境变量是否生效
   $env:CUDA_VISIBLE_DEVICES
   → 应显示 "0"

2. 手动设置（临时）
   $env:CUDA_VISIBLE_DEVICES = "0"
   python your_script.py

3. 验证 CUDA
   python test_cuda.py
   → 应显示 "CUDA可用: True"
